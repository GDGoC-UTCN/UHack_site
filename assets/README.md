## Notes
- Gallery images: recomandat 800×600px sau mai mari, format JPG/WebP
- Partner logos: recomandat 400×200px fundal transparent, format PNG
- Team photos: recomandat pătrat 400×400px, format JPG
- Dacă imaginile lipsesc, site-ul afișează automat fallback-uri grafice (inițiale / placeholder-uri)
- Logo-urile partenerilor sunt convertite automat la grayscale prin CSS
- Pozele echipei sunt convertite automat la grayscale prin CSS (consistent cu tema)
